Técnico 02 / 06

Arquitectura Distribuida del Sistema

El ecosistema biométrico se compone de tres módulos modulares integrados en red local que se comunican de forma asíncrona:

⚛️

Frontend (React + Vite)

Aplicación de interfaz de usuario reactiva, visor de cámara web y retroalimentación binaural mediante Web Audio API en el puerto 5173.

🟢

Backend (Node.js + Express)

Servidor de API REST de negocios, conector inteligente a MySQL y gestor de subida de imágenes (Multer) corriendo en el puerto 3000.

🐍

Motor Biométrico (Python Flask)

Servicio de visión artificial. Utiliza Haar Cascades para recortar rostros y LBPH (OpenCV) para entrenamiento y reconocimiento en el puerto 5000.

http://localhost:3000/api/docs
Técnico 03 / 06

Requisitos del Entorno (Windows)

Antes de iniciar el sistema, asegúrese de tener configurados los siguientes componentes de hardware y software en su equipo Windows:

💻

Hardware Mínimo Requerido

Procesador Intel Core i3 (4ta Gen) o AMD Ryzen 3, 8 GB de memoria RAM y Cámara Web USB HD (mínimo 720p) con buena iluminación facial.

⚙️

Servidores Locales y Runtimes

XAMPP instalado (con MySQL activo en puerto 3306), Node.js (versión LTS 18 o superior) y Python (versión 3.9 o superior).

📦

Bibliotecas de Visión Artificial

Módulos de Python requeridos para el motor biométrico: opencv-contrib-python (LBPH), Flask y numpy.

Técnico 04 / 06

Preparación de MySQL en XAMPP

El sistema utiliza una base de datos relacional para el control financiero, histórico de check-ins y registros de auditoría.

1

Iniciar MySQL

Abra el panel de control de XAMPP y haga clic en "Start" junto a MySQL (debe encenderse en verde en el puerto 3306).

2

Creación Automática de Tablas

No es necesario crear la base de datos manualmente. Al arrancar el Backend de Node.js por primera vez, este creará de forma automatizada las tablas y relaciones.

3

Sembrar Registros Demo

Abra una consola en backend/ y ejecute el seeder:
npm run seed
Esto poblará la BD con 5 socios muestra, registros de check-in e inicios de sesión administrativos.

http://localhost/phpmyadmin
Técnico 05 / 06

Despliegue y Puesta en Marcha

Para facilitar el encendido del ecosistema de software y evitar la apertura manual de consolas, se provee un script de arranque automatizado.

1

Ejecutar iniciar_sistema.bat

Haga doble clic en el archivo iniciar_sistema.bat ubicado en la raíz del proyecto para iniciar las 3 capas del sistema.

2

Las 3 Capas en Segundo Plano

Se abrirán tres consolas de comando de Windows independientes que levantarán el Frontend (React), el Backend (Node.js) y el Motor de IA (Python Flask).

3

Abrir el Navegador

Ingrese al navegador de su preferencia y acceda a la dirección local del Frontend:
http://localhost:5173

Técnico 06 / 06

Guía de Solución de Problemas

Errores técnicos comunes de primer despliegue y sus respectivas soluciones paso a paso:

⚠️

Conflicto de Puertos (3000 / 5000 / 3306)

Si alguna consola indica "Port already in use", verifique que no posea otra terminal, instancia de base de datos o aplicación levantada en el mismo puerto.

🔌

Error de Comunicación con el Motor

Si el Frontend no detecta la cámara o arroja error del reconocedor, confirme que el motor de Python Flask en el puerto 5000 esté corriendo e instalado con opencv-contrib-python.

🗄️

MySQL Connection Refused

Verifique en el panel de XAMPP que MySQL esté de color verde. Confirme que la contraseña y usuario en el archivo de entorno del backend coincidan con los de su base de datos local.
