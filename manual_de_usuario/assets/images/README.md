### 💡 Instrucciones para Tomar Capturas Profesionales:
1. Abre tu navegador en la sección correspondiente de **DevMind**.
2. Presiona **F11** en tu teclado para activar el **Modo de Pantalla Completa** del navegador (esto eliminará la barra de Windows, pestañas y URL para dar una captura limpia y profesional).
3. Si el área es muy grande, puedes hacer zoom out (`Ctrl` + `-`) en el navegador para encuadrarla mejor.
4. Presiona `Windows` + `Shift` + `S` (o la herramienta de recortes de tu OS) y recorta el área exacta de la app.
5. Guarda la imagen en esta carpeta (`manual_de_usuario/assets/images/`) con su respectivo nombre en formato **PNG**.
6. ¡Refresca la página del manual interactivo en tu navegador (`index.html`) y verás tu propia app insertada automáticamente en los marcos de diseño!
